# v7 验收结果

环境：本机 Windows，Codex 26.1007.2314.0，.NET 自包含 x64 发布。

## 实际启动与异常恢复

| 项目 | 结果 |
| --- | --- |
| 以普通用户登记登录计划任务 | 通过，无需管理员或保存密码 |
| 从真实计划任务启动已安装守护 | 通过，任务实际运行且管道返回 v7 |
| 启动文件夹与任务同时进入 | 通过，仅保留一个常驻守护 |

| 关闭后执行登录入口 | 通过，立即退出，不重新启用 |
| 原主题配置 | 恢复并保留，不知火赤月轮舞、原遮罩、100% 动效 |

实际启动验收脚本为 `work/test_logon_integration.ps1`。任务直接运行 ProgramData 下的守护，没有额外常驻启动器。

现场曾发现用户目录下组件在计划任务环境不可见，以及不同启动入口之间关闭状态未同步的问题；已改为 ProgramData 中受限用户目录和共用的原子配置文件。

验收脚本为 `work/test_native_logon_v7.ps1`。没有读取或公开用户聊天内容。
