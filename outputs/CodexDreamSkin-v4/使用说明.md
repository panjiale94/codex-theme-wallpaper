# Codex 动态皮肤 v4（Windows x64）

## 1. 需求与实现

在 Codex 桌面软件内部显示动态主题。新增 4 套中央全身人物构图，保留前版 6 套，共 10 套。

| 主题 | 主要动态效果 |
| --- | --- |
| 不知火 · 神社双焰 | 蓝红旋焰、伸缩火舌、蝶群环流、斜雨和流雾 |
| 不知火 · 天雷夜雨 | 快速斜雨、远景雷电、青紫流焰、风场 |
| 不知火 · 月海潮汐 | 持续推进的波浪、蓝焰蝶群、海雾 |
| 不知火 · 赤月轮舞 | 赤金旋转火轮、火舌、快速余烬与蝶群 |

新主题还使用 GPU 局部风场，让发尾、衣摆和扇边区域发生波动。人物主体采用插画局部动画，不是完整 Live2D 骨骼动画或真人动作视频。需要整个人物动作时，可直接导入对应 MP4 / WebM 动态壁纸。

## 2. 使用

1. 双击 `CodexDreamSkin.exe`。已经包含 .NET 8 运行时，无需安装开发环境。
2. 选择前四张中央人物新主题；动效强度会自动设为 100%。
3. 点击“应用主题 / 启动 Codex”。已启用时点击主题即可切换。
4. 关闭设置窗口，背景继续播放。
5. 需要关闭时，重新打开工具，点击“关闭效果”，恢复原来的界面主题并退出后台守护。

建议面板遮罩 20%～35%。降低遮罩可更清楚看见人物；文字不会随窗口整体变淡。“强动效 100%”按钮可以恢复最大动效。

首次使用若 Codex 没有启用本机调试连接，请完全退出 Codex，再由工具启动。升级 v3 时，v4 会识别并自动替换旧版后台守护。

## 3. 代码与构建

源码在相邻的 `CodexDreamSkin-v4-source.zip`，项目使用 C# / .NET 8 / WPF。

```powershell
dotnet publish CodexDreamSkin.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

`Assets/v4-generation-prompts.json` 保存四套新插画的完整生成提示词；素材由内置 image_gen 工具参考用户截图生成。动态部分在 `EffectRuntime.js` 中独立实现。主题元数据在 `ThemeCatalog.cs` 中，可维护和扩展。

## 4. 本机配置

- 前台与后台通过当前 Windows 用户专用命名管道交换小型 JSON 命令。
- 后台连接本机 `127.0.0.1` 上 Codex 的动态调试端口，维持页面刷新后的皮肤。
- 设置和日志位于 `%AppData%\CodexDreamSkin`；不改变 Codex 的签名安装文件。
- 图片 / GIF / MP4 / WebM 可自行导入；视频静音循环，单文件上限 100 MB。
- Wallpaper Engine 场景包不能直接作为视频导入；MP4 / WebM 壁纸可导入。

## 5. 调试与验收

已验证四主题解码和动画运行、切换后特效画布不累积、关闭前台后继续、刷新后继续、重新打开并关闭效果后恢复原主题且保持关闭。动态演示见“四款强动效预览.mp4”；主题库截图与各主题实际 Codex 截图一并提供。

无效果时先检查是否由工具启动 Codex；报素材错误时检查文件是否移动、超过大小上限或视频编码不受支持。日志为 `skin.log`。

## 6. 限制

关闭的是设置窗口，仍有一个后台进程维持连接。退出整个后台进程后，页面刷新无法持续注入；本版本没有安装开机启动项。最小化或隐藏 Codex 时暂停绘制以节约资源，重新显示后继续。没有 GPU 风场支持时保留原插画及 Canvas 特效。强动效增加 GPU 使用，觉得耗电可降低强度；Codex 界面更新后可能需要适配样式。
