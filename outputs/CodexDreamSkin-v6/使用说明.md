# Codex 动态皮肤 v6

## 1. 需求分析

关闭主题设置窗口后继续播放；退出再正常打开 Codex 自动恢复；Windows 登录后第一次打开 Codex 自动恢复。保持强动效并减少后台内存。

v5 失效的实际原因：守护虽仍在运行，但普通 Codex 入口没有本机主题连接参数，因此无法注入背景。

## 2. 方案

v6 在轻量守护中加入普通启动检测，无需常驻设置窗口，也不提前启动 Codex。只接管启动不超过 15 秒、安装路径和资料目录均匹配的 Codex 主进程。保留原参数、补齐连接参数后自动快速重新启动一次。已有连接的客户端不重复重启，已经运行的旧客户端不被中断。

后台无 WPF，不缓存整张图片或视频；媒体通过本机连接按 16 KB 分块传输。动画继续由 Codex 内部渲染。

## 3. 部署与使用

完整解压软件包，保留以下文件：

```text
CodexDreamSkin.exe
CodexDreamSkin.Worker.exe
Themes/（9 张主题图片）
```

1. 打开 `CodexDreamSkin.exe`，选择主题并应用。
2. 保持“Windows 登录后自动恢复”勾选。
3. 首次升级时，如果 Codex 已运行且没有主题连接，从“文件 → 退出”退出一次，再从平时的普通入口打开。
4. 以后退出再打开，由后台自动恢复；设置窗口可以关闭。
5. 关闭效果时，重新打开设置并点击“关闭效果”。它会撤销启动项、还原快捷方式并结束守护。

软件目录应固定。移动后重新打开设置并应用一次，更新启动路径。

## 4. 本机配置

- 参数：`HKCU\Software\CodexDreamSkin\Profiles`，保留上次主题、遮罩和动效强度。
- 登录启动：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\CodexDreamSkin`。
- 日志及快捷方式备份：`%AppData%\CodexDreamSkin`。
- 连接：当前用户专用命名管道，以及 `127.0.0.1` 的动态调试端口。
- 不修改 Codex 安装文件，不安装系统服务。

## 5. 调试与验收

已验证：不带调试参数直接启动原生客户端自动恢复、完整退出重开、页面刷新、四款强动效、MP4 播放、模拟登录后普通首次打开、关闭效果和禁用后的登录守护退出。

本机后台等待时工作集 48.9 MB、私有提交 13.7 MB；播放时工作集 65.9～66.7 MB、私有提交约 31 MB。无 WPF 模块，155 个背景粒子及 GPU 风场仍启用。内存数值不包含 Codex 自身渲染/GPU 内存。

没有实际重启用户电脑，也没有结束当前工作实例来测试真实 Store 应用列表入口。

## 6. 限制与排查

- 普通启动可能短暂重新打开一次。程序先请求关闭新窗口；若未退出则结束这个新进程树，再启动带连接参数的实例。只处理启动阶段，已有工作实例不自动重启。
- 如果 Windows 禁用了登录启动项，自动恢复守护无法启动，需要在系统启动设置中重新启用。
- 如果打开 Codex 时守护尚未启动，且 Codex 已运行超过 15 秒，则需在启动守护后退出重开一次。
- 登录验证使用模拟，不代表已进行整机重启验收。
- Codex 更新安装路径或界面结构后可能需要适配。异常原因记录在 `skin.log`。
- 自定义媒体上限 100 MB；视频推荐 H.264 MP4 或 WebM，静音循环。
